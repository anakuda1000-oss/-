#全体の流れと処理内容
#起動確認

#最初に print と input で「y で起動、n で終了」の選択を求めます。

#y を入力するとループが始まり、n を入力すると「終了」と表示してプログラムが終わります。

#メインループ（while True）

#y が選ばれた場合、無限ループに入り、ユーザーが「4（終了）」を選ぶまで処理を繰り返します。

#以下の4つの選択肢（メニュー）が表示されます：

#1: 収入 … 金額を入力すると、現在の残高にその額が足されます。

#2: 支出 … 金額を入力すると、現在の残高からその額が引かれます。

#3: 残高 … 現在の残高を表示します。

#4: 終了 … ループを抜け出し、アプリを終了します。

#入力ミスへの対策

#1〜4 以外の数字が入力された場合は、「指定した数を入れてください（１～４）」とエラーメッセージを出して、再度メニューに戻る親切設計になっています。
